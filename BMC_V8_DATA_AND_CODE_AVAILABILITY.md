# BMC simulated-editor v8 data and code availability

## Manuscript wording

The curated prescription dataset and processed outputs are provided in Additional files 2, 3 and 5-9. Public transcriptomic data were obtained from the NCBI Gene Expression Omnibus under GSE247531, GSE165870 and GSE145668; no new primary human transcriptomic data were generated. Analysis code and selected derived source tables, including data underlying Fig. 8 and Supplementary Figs. S14-S16, are available at https://github.com/yuyi-wang-imu/aa-donor-recovery-perturbation. The immutable software and derived-data release v0.1.0 remains archived at Zenodo (https://doi.org/10.5281/zenodo.21837457; archived commit `b850d7e6a6141962d3a2d38021d0780e3c5907a1`); this DOI identifies the archived v0.1.0 release and does not imply that later manuscript-specific revisions are contained in that ZIP file. Repository-authored code is distributed under the BSD-3-Clause license. External software, model assets and licensed databases retain their original access terms. Complete saved production records for five ligand-containing 100 ns trajectories and one matched 100 ns HIF1A-ARNT apo reference (six trajectories; 600 ns total; 13.2 GB) are retained institutionally but are not duplicated in the Additional files because of their aggregate size. Editors and peer reviewers may request these retained files through the institutional corresponding-author route (Wendurige, `wendurige@imu.edu.cn`) for verification of the reported analyses. Derived time series, final-window summaries, analysis scripts and available simulation-input metadata are public in the repository.
