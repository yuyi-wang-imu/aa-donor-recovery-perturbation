# PLOS ONE submission alignment

Prepared on 10 September 2026.

The current journal-format package is a PLOS ONE Research Article. The flat
upload directory contains 38 files: `Manuscript.docx`, `Cover_Letter.docx`,
`Fig1.tif` through `Fig8.tif`, `S1_Fig.pdf` through `S16_Fig.pdf`, `S1_Table.xlsx`
through `S10_Table.xlsx`, and `S11_Data.xlsx` plus `S12_Data.xlsx`.

This conversion changes presentation only. The main figures are separate LZW-
compressed TIFF files with 300 dpi metadata; supporting-figure PDFs are split
into one file per supporting figure; supporting tables are split and named in
PLOS style; figure captions follow the first citing paragraph; and supporting-
information captions are collected after the references. Analysis values,
candidate membership, rankings, and evidence interpretations are unchanged.

The immutable Zenodo v0.1.0 software and derived-data snapshot remains
<https://doi.org/10.5281/zenodo.21837457> and corresponds to commit
`b850d7e6a6141962d3a2d38021d0780e3c5907a1`. Later repository maintenance does
not alter that archived version. No public DOI is claimed for the complete raw
molecular-dynamics trajectories; their access boundary is described in
`MD_DATASET.md`.

Exact sizes and SHA-256 values for the current upload files are listed in
`PLOS_ONE_ASSET_CHECKSUMS.tsv`. Submission-package binaries are held separately
and are not committed to this repository.
