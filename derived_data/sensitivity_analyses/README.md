# Simulated-editor sensitivity analyses

This directory contains the machine-readable outcome-blind ranking, six-month-only donor-trajectory, permutation-null, baseline-only WGCNA, and molecular-dynamics coverage outputs added for the final BMC Pharmacology and Toxicology v8 candidate. `Additional_file_9_Sensitivity_Analysis_Source_Data.xlsx` is the submission workbook assembled from these tables.

The analyses assess robustness under prespecified or outcome-independent perturbations. They do not revise the primary candidate order and do not establish clinical efficacy, direct binding, or independent external validation. The `v2` trajectory files supersede the incomplete `v1` attempt retained outside the public repository.

Complete molecular-dynamics trajectories are not stored here. The public inventory covers derived time series, summaries, analysis scripts, and available input metadata; the six complete 100-ns production records (13.2 GB total) remain institutionally retained.
