# Targeted docking source data

`Additional_file_8_Targeted_Docking_Source_Data.xlsx` is the machine-readable submission source workbook for the 23-ligand, three-seed TOP2A and HIF1A targeted screens, the AlphaFold HIF1A PAS-B receptor-model sensitivity analysis, and TOP2A ANP redocking.

Scores are computational model outputs used for within-target pose prioritization and exploratory structural context. They are not experimental affinities and were not used to determine candidate-gene membership or ranking.
