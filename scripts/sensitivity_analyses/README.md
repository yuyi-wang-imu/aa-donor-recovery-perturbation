# Sensitivity-analysis scripts

These scripts generate or summarize the outcome-blind ranking, six-month-only donor trajectory, deterministic permutation nulls, and one-profile-per-participant baseline-only WGCNA analyses reported in the final v8 manuscript candidate and Supplementary Table S10 source workbook.

The scripts expect project-specific input paths documented in their headers. They do not download licensed resources, Geneformer model assets, or raw molecular-dynamics trajectories.
